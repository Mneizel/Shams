# شمس المعارف — محرّك تفاعلي (Shams al-Maʿārif Engine)

مشروع شخصي محلي. الهدف: تطبيق المُحرّك الحسابي/المنطقي لكتاب *شمس المعارف الكبرى* (وما يتّصل به:
*شمس المعارف الصغرى*، *منبع أصول الحكمة*) تطبيقًا أمينًا، بحيث تُنتِج نفس مخرجات مَن يمارس الكتاب
حرفيًا — لاستخدامها أداةً لتفكيك ادّعاءات المشتغلين بالكتاب في النقاش.

> صاحب المشروع لا ديني ولا يؤمن بهذه الأمور. الغرض نقدي/تعليمي: بيان أن "النتيجة الروحانية"
> عملية حسابية حتمية مكشوفة.

## البنية

```
shams-maarif-engine/
├─ engines/            محرّك مستقل لكل باب، ES module صافٍ، بدون سيرفر
│  ├─ abjad.js         حساب الجُمّل: حروف↔أرقام (كبير مشرقي/مغربي، صغير)، بسط، تكسير، طبائع
│  ├─ awfaq.js         الأوفاق: توليد أي مربّع عددي، وفق الكواكب، وفق الاسم، تحقّق
│  ├─ falak.js         الفلك: حاكم اليوم/الساعة، مواقع الكواكب، الطالع، المنازل ٢٨ (offline)
│  ├─ asma-khuddam.js  من الاسم + اسم الأم: عنصر/كوكب/برج/منزلة/خادم/ملَك/يوم/ساعة/بخور
│  ├─ jafr.js          الجفر: دوائر الحروف، التكسير، طرق الاستخراج الموثّقة
│  ├─ zairja.js        زايرجة العالم (وصف ابن خلدون) — آلة استخراج جواب حرفية
│  ├─ talisman.js      رسم الأختام/الطلاسم/الحروف المقطّعة/بُدُوح (SVG)
│  └─ prediction.js    مُركِّب: يجمع مخرجات المحرّكات في "طالع" حتمي
├─ data/               جداول مرجعية JSON (مفصولة عن المنطق)
├─ vendor/             مكتبات طرف ثالث (astronomy-engine — رخصة MIT، offline)
├─ text/              نصوص المصادر المجمّعة + فهرس الطبعات والاختلافات (تُعرض عند الطلب فقط)
├─ tests/              اختبارات Node
└─ web/                الواجهة النهائية (تُبنى بعد اختيار تصميم من ٥ mockups)
```

## قواعد المحتوى (متفَّق عليها)

1. كل المحرّكات الحسابية تعمل لكل الأبواب بلا استثناء (محبة/تفريق/أذى/حجب/تسخير)، وتُخرج
   نفس نتيجة الممارس. الأختام والطلاسم تُرسَم لكل باب. نصّ الكتاب يُعرض كاملًا كمرجع.
2. الاستثناء الوحيد: وصفات التبخير/الخلطات التي تُحرق أو تُبتلع لا تُصاغ كبطاقة "افعل في البيت"
   بمقادير نظيفة. المكوّن السامّ فعليًا (زرنيخ، زئبق، داتورا/جوز ماثل، سيكران…) يبقى موسومًا
   كسُمّ. هذا تحذير تسمّم لا تفنيد.
3. اختلافات الطبعات تُخزَّن ولا تُعرض إلا عند الطلب.

## التشغيل

- **الأسهل — ملفّ واحد:** انقر نقرًا مزدوجًا على **`web/شمس-المعارف.html`** ‏— يفتح كلَّ شيء
  بلا سيرفر وبلا إنترنت (كلُّ المحرّكات والبيانات مدموجةٌ فيه). لظهور صور الأرواح انسخ
  مجلّد `assets/` بجانبه.
- **للتطوير:** `node tools/serve.js` ثم `http://localhost:8080` (يحمّل الوحدات مباشرةً).
- **إعادة بناء الملفّ الواحد بعد أيّ تعديل:** `node tools/build-standalone.js`
- **الاختبارات:** `node tests/run.js` (٢٠٣ ناجحة) · تجربة كاملة: `node tests/demo-user.js`
- **بيانات مُولَّدة:** `node tools/build-corpus.js` · `node tools/build-prompts.js`

الواجهة: شريطٌ علويّ فيه بحثٌ ثابتٌ + مفتاح «وضع الكشف»؛ شريطٌ جانبيّ بكلّ الأدوات +
«بطاقتي» (اسم/أمّ/سؤال/ميلاد/موقع تُستعمل في كلّ مكان)؛ لوحةٌ لكلّ محرّك؛ ولوحة «الكُتيب»
تشرح كلّ أداة. زرّ «وجهًا لوجه» يقلب أيّ نتيجةٍ إلى: دعوى المشعوذ / ما جرى فعليًّا.
